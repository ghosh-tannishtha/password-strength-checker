# password-strength-checker
A Java console-based password strength checker that evaluates passwords based on length, digits, uppercase, lowercase, and special characters.

# Password Strength Checker (Java)

This is a simple Java console project that checks the strength of a password based on:

- Length (minimum 8 characters)
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

## Features
- Interactive menu system
- Password analysis report
- Strength score calculation
- Smart suggestions for improvement

## How to Run

```bash
javac PasswordValidator.java
java PasswordValidator
